చరిత్ర · భక్తి, సూఫీ ఉద్యమాలు

ముందు అర్థం చేసుకోండి

ఇది ఏమిటి? భక్తి అంటే వ్యక్తిగత దేవునిపై ప్రేమపూర్వక భక్తి; సూఫీ తత్వం ఇస్లాంలోని ఆధ్యాత్మిక శాఖ, ప్రేమ ద్వారా దేవునితో ఐక్యం కోసం అన్వేషణ. కఠిన ఆచారాలు, కులం, పురోహిత నియంత్రణ సామాన్యులను బాధించిన సమయంలో 6 నుండి 17వ శతాబ్దాల మధ్య మధ్యయుగ భారత్‌లో రెండూ ఎదిగాయి. దేవుడిని ప్రేమ ద్వారా చేరవచ్చు, ఆచారం, పుట్టుక, పాండిత్యం ద్వారా కాదు అని రెండూ చెప్పాయి; రెండూ స్థానిక భాషలు, సంగీతం వాడాయి; భారత సమాజం, భాష, మత సామరస్యాన్ని తీర్చిదిద్దాయి. భక్తి (దక్షిణం → ఉత్తరం → పశ్చిమం) → సూఫీ తత్వం (సిల్సిలాలు, భావనలు) → సిక్కు మతం → ప్రభావం క్రమంలో నేర్చుకోండి.

భక్తి ఉద్యమం
రాజస్థాన్ కృష్ణ భక్త కవయిత్రి మీరాబాయి కాంగ్రా చిత్రం. (Photo: Wikimedia Commons, free licence)

1. దక్షిణాన భక్తి (6–13వ శతాబ్దం)

సమూహంఅంశాలు
ఆళ్వార్లు (విష్ణు)12 మంది భక్తులు; తమిళ గీతాలు నాలాయిర దివ్య ప్రబంధంగా సంకలనం. నమ్మాళ్వార్, తిరుమంగై, పెరియాళ్వార్, ఆండాళ్ (స్త్రీ ఆళ్వార్, విష్ణుపై ప్రేమను పాడింది: *తిరుప్పావై*).
నాయనార్లు (శివ)63 మంది భక్తులు; గీతాలు తేవారం (అప్పర్, సంబంధర్, సుందరర్), తిరుమురైగా సంకలనం; జీవిత కథలు పెరియపురాణంలో (శేక్కిళార్). స్త్రీ భక్తురాలు కారైక్కల్ అమ్మైయార్.
ఆచార్యులుశంకరుడు (8వ శ., అద్వైతం); రామానుజుడు (11–12వ శ., విశిష్టాద్వైతం, *శ్రీభాష్యం*, శ్రీ వైష్ణవం); మధ్వుడు (13వ శ., ద్వైతం); నింబార్కుడు (ద్వైతాద్వైతం); వల్లభుడు (శుద్ధాద్వైతం, పుష్టిమార్గం).
బసవన్న (12వ శ., కర్ణాటక)కళ్యాణలో బిజ్జలుని మంత్రి; వీరశైవ / లింగాయత్ ఉద్యమం స్థాపించాడు; అనుభవ మంటపం; కన్నడంలో వచనాలు రాశాడు; కులం, విగ్రహారాధన, ఆచారాలను వ్యతిరేకించాడు; భక్తులు అక్క మహాదేవి, అల్లమ ప్రభు.

2. ఉత్తరాన భక్తి

భక్తుడుఅంశాలు
రామానంద (14–15వ శ., కాశీ)రాముని భక్తుడు; సంస్కృతం కాక హిందీలో బోధించాడు; అన్ని కులాల శిష్యులు: కబీర్ (నేతగాడు), రవిదాస్ (చర్మకారుడు), సేన (మంగలి), ధన్నా (జాట్), పీపా (రాజపుత్ర).
కబీర్ (సుమారు 1440–1518)నిర్గుణ (రూపం లేని) దేవుడు; హిందూ–ముస్లిం ఐక్యత; విగ్రహారాధన, కులం, తీర్థయాత్ర, వ్యర్థ ఆచారాలను విమర్శించాడు; రచనలు: దోహాలు, సాఖీలు, సబద్‌లు, రమైనీలు, బీజక్లో సంకలనం; అనుచరులు: కబీర్‌పంథీలు.
రవిదాస్ (రైదాస్)కాశీ చర్మకార భక్తుడు; నిర్గుణ భక్తి; పద్యాలు గురు గ్రంథ్ సాహిబ్‌లో చేరాయి; రవిదాసియా సమాజం.
గురు నానక్ (1469–1539)తల్వండి (నన్కానా సాహిబ్) లో జననం; ఒకే నిరాకార దేవుడు (ఇక్ ఓంకార్), *జపుజీ*; విగ్రహారాధన, కులం, ఆచారాలను తిరస్కరించాడు; లంగర్ (సామూహిక వంటశాల), సంగత్ (సమూహం), పంగత్ (కలిసి భోజనం) ప్రారంభించాడు; కర్తార్‌పూర్లో స్థిరపడ్డాడు; ఉదాసీ యాత్రలు చేశాడు.
చైతన్య (1486–1534)నడియా (బెంగాల్)లో జననం; కృష్ణ భక్తి (గౌడీయ వైష్ణవం); సంకీర్తన (సామూహిక గానం); అచింత్య భేదాభేద తత్వం; పూరీ (ఒడిశా), బృందావన్లో ఉద్యమం వ్యాప్తి.
తులసీదాసు (1532–1623)కాశీ; రామ భక్తి (సగుణ); రామచరితమానస్ అవధీలో (అక్బర్ కాలం); *వినయ పత్రిక*, *కవితావళి* కూడా.
సూర్‌దాస్ (సుమారు 1483–1563)అంధ కవి; కృష్ణ భక్తి; సూర్ సాగర్; వల్లభుని శిష్యుడు; బ్రజ్ భాష; ఆగ్రా సమీపంలో నివసించాడు.
మీరాబాయి (16వ శ.)మేర్తా (రాజస్థాన్) రాథోడ్ రాకుమారి, మేవాడ్ భోజ్ రాజ్ భార్య; కృష్ణ భక్తి; రాజస్థానీ/బ్రజ్లో గీతాలు; కుటుంబ ఆచారాలను ధిక్కరించింది; రవిదాస్‌ను గురువుగా భావించింది.
శంకరదేవుడు (1449–1568, అస్సాం)ఏకశరణ ధర్మం (ఒకే దేవుడు కృష్ణునికి భక్తి); నామ్‌ఘర్ (ప్రార్థనా మందిరం); కీర్తన ఘోష; అంకియా నాట్ (ఏకాంకికలు); సత్రాలు (మఠాలు).
రాముడు, సీతకు భక్తితో తులసీదాసు (రాజా సంసార్ చంద్‌తో), కాంగ్రా చిత్రం: సగుణ సంప్రదాయం. (Photo: Wikimedia Commons, free licence)

3. పశ్చిమ, దక్షిణ, ఆంధ్ర భక్తి

ప్రాంతంభక్తులు, అంశాలు
మహారాష్ట్ర (వార్కరీ సంప్రదాయం; పండరీపురం విఠోబా)జ్ఞానేశ్వర్ (*జ్ఞానేశ్వరి*, 1290), నామదేవ్ (దర్జీ), ఏకనాథ్, తుకారాం (*అభంగాలు*), జనాబాయి; రామదాసు (*దాసబోధ*), శివాజీ గురువు.
గుజరాత్, కర్ణాటకనర్సింహ మెహతా (*వైష్ణవ్ జన్ తో*); పురందరదాసు, కనకదాసు (హరిదాస సంప్రదాయం).
ఆంధ్ర, తెలంగాణఅన్నమాచార్య (తిరుమల, వేంకటేశ్వర సంకీర్తనలు); పోతన (*భాగవతం*); భద్రాచలంలో కంచర్ల గోపన్న (రామదాసు) (రామ భక్తి); క్షేత్రయ్య (కృష్ణ పదాలు, మువ్వ గోపాల); త్యాగరాజు (తెలుగు కీర్తనలు, తంజావూరు); వేమన (కులం, ఆచారాలకు వ్యతిరేక పద్యాలు, 17వ శ.); పోతులూరి వీరబ్రహ్మం (*కాలజ్ఞానం*, కడప ప్రాంతం); తిరుపతితో రామానుజుని శ్రీవైష్ణవ అనుబంధం; రాయలసీమ–కర్ణాటక సరిహద్దులో వీరశైవ, హరిదాస ప్రభావం.

4. భక్తి బోధనలు

  • ఒకే దేవుడు, ఆచారాలు, యజ్ఞాలు, పురోహితుల ద్వారా కాక ప్రేమ, శరణాగతి ద్వారా చేరవచ్చు. నిర్గుణ (రూపం లేని దేవుడు: కబీర్, నానక్), సగుణ (రూపం గల దేవుడు: రాముడు, కృష్ణుడు: తులసీదాసు, సూర్‌దాస్, మీరాబాయి).
  • కులం, అంటరానితనానికి వ్యతిరేకం; అన్ని కులాల నుండి భక్తులు; స్త్రీ భక్తులు (ఆండాళ్, అక్క మహాదేవి, మీరాబాయి, జనాబాయి); గురువు తప్పనిసరి; స్థానిక భాషలో గానం (కీర్తన, భజన).

5. సూఫీ తత్వం

ప్రధాన సూఫీ సిల్సిలాలు
అజ్మీర్ షరీఫ్ దర్గా, ఖ్వాజా మొయినుద్దీన్ చిష్తీ సమాధి, అన్ని మతాల వారు సందర్శిస్తారు. (Photo: Wikimedia Commons, free licence)
పదంఅర్థం
సిల్సిలాగురు–శిష్యుల సంప్రదాయ శ్రేణి; 12–14 సిల్సిలాలు భారత్‌కు వచ్చాయి (చిష్తీ, సుహ్రవర్దీ, ఖాదిరీ, నక్ష్‌బందీ, ఫిర్దౌసీ, షత్తారీ మొదలైనవి).
పీర్–మురీద్, ఖాన్‌ఖాగురువు, శిష్యుడు; ఖాన్‌ఖా సూఫీ నివసించి, బోధించి, పేదలకు అన్నం పెట్టే ఆశ్రమం.
సమా, జిక్ర్సమా = భక్తి సంగీతం, గానం (ఖవ్వాలీ); జిక్ర్ = దేవుని నామ జపం.
వహదత్-ఉల్-వజూద్'అస్తిత్వ ఐక్యం' (ఇబ్న్ అరబీ): సర్వం దేవుడే. షేక్ అహ్మద్ సిర్హిందీ (నక్ష్‌బందీ) దీన్ని వ్యతిరేకించి వహదత్-ఉష్-షుహూద్ (సాక్ష్య ఐక్యం) బోధించాడు; ముజద్దిద్ అల్ఫ్-ఇ-సానీ (రెండవ సహస్రాబ్ది పునరుద్ధారకుడు) అంటారు.
ఫనా, బఖాఫనా = దేవునిలో తనను కోల్పోవడం; బఖా = దేవునిలో కొనసాగడం.
మల్ఫూజాత్, ఉర్స్మల్ఫూజాత్ = నమోదైన బోధనలు (ఉదా. నిజాముద్దీన్ ఔలియా *ఫవాయిద్-ఉల్-ఫుఆద్*, అమీర్ హసన్ సిజ్జీ); ఉర్స్ = భక్తుని వర్ధంతి, దర్గాలో ఉత్సవం.
సిల్సిలాభక్తులు, లక్షణాలు
చిష్తీఖ్వాజా మొయినుద్దీన్ చిష్తీ (అజ్మీర్, మరణం 1236) తెచ్చాడు; కుతుబుద్దీన్ భక్తియార్ కాకీ (ఢిల్లీ); బాబా ఫరీద్ (పాక్‌పట్టన్; పద్యాలు గురు గ్రంథ్ సాహిబ్‌లో); నిజాముద్దీన్ ఔలియా (ఢిల్లీ, మరణం 1325, శిష్యుడు అమీర్ ఖుస్రో); నసీరుద్దీన్ చిరాగ్-ఇ-ఢిల్లీ; గేసూ దరాజ్ (గుల్బర్గా). సరళంగా జీవించి, పాలకులకు దూరంగా ఉండి, రాజ్య పదవులు, మంజూరులను తిరస్కరించి, సంగీతాన్ని (సమా) ప్రేమించారు; ఫతేపూర్ సిక్రీ సలీం చిష్తీ అక్బర్‌ను ఆశీర్వదించాడు.
సుహ్రవర్దీషేక్ బహావుద్దీన్ జకరియా (ముల్తాన్), హమీదుద్దీన్ నాగౌరీ; ప్రభుత్వ పదవులు, మంజూరులను అంగీకరించి సుల్తానులతో సన్నిహితంగా పనిచేశారు; సింధ్, పంజాబ్‌లో బలంగా ఉన్నారు.
ఖాదిరీఅబ్దుల్ ఖాదిర్ జీలానీ స్థాపించాడు; 15వ శతాబ్దంలో భారత్‌కు వచ్చింది (ఉచ్, సింధ్); మియాన్ మీర్ (లాహోర్); దారా షికోహ్ అనుచరుడు. పంజాబ్, కాశ్మీర్, దక్కన్‌లో ప్రసిద్ధం.
నక్ష్‌బందీఅక్బర్ కాలంలో ఖ్వాజా బాకీ బిల్లాతో వచ్చింది; షేక్ అహ్మద్ సిర్హిందీ షరియాను నొక్కిచెప్పి అక్బర్ ఉదార ఆలోచనలను వ్యతిరేకించాడు; తర్వాత షా వలీఉల్లా.
రిషి సంప్రదాయం (కాశ్మీర్)షేక్ నూరుద్దీన్ నూరానీ (నుంద్ రిషి), శైవ ఆధ్యాత్మిక కవయిత్రి లల్ల ద్ (లల్లేశ్వరి), వాఖ్‌లు రచించి సూఫీ, శైవ భావాలను కలిపారు.
ఆంధ్రలో సూఫీ దర్గాలుకడప (అమీన్ పీర్ / పెద్ద దర్గా), నెల్లూరు (బారా షహీద్ దర్గా), పెనుగొండ (బాబా ఫఖ్రుద్దీన్ దర్గా): హిందువులు, ముస్లింలు ఇద్దరూ ఉర్స్‌కు హాజరయ్యే ప్రధాన దర్గాలు.

6. సిక్కు మతం: పది గురువులు

అమృత్‌సర్ హర్‌మందిర్ సాహిబ్ (స్వర్ణ దేవాలయం), గురు రామ్ దాస్ ప్రారంభించి గురు అర్జన్ కట్టించారు. (Photo: Wikimedia Commons, free licence)
గురువుతోడ్పాటు
1 నానక్స్థాపకుడు; ఒకే దేవుడు; లంగర్, సంగత్, పంగత్.
2 అంగద్గురుముఖి లిపి అభివృద్ధి.
3 అమర్ దాస్లంగర్ బలపరిచాడు; సతి, పరదాలను వ్యతిరేకించాడు; మంజీ బోధనా విధానం; అక్బర్ ఆయన లంగర్‌ను సందర్శించాడు.
4 రామ్ దాస్అమృత్‌సర్ స్థాపించాడు; అక్బర్ భూమి ఇచ్చాడు.
5 అర్జన్హర్‌మందిర్ సాహిబ్ కట్టించాడు; ఆది గ్రంథ్ (1604) సంకలనం; జహంగీర్ ఉరితీశాడు (1606) (తొలి సిక్కు అమరుడు).
6 హరగోవింద్మీరీ–పీరీ (లౌకిక, ఆధ్యాత్మిక అధికారం); సైన్యం; అకాల్ తఖ్త్.
7 హర్ రాయ్, 8 హర్ కిషన్ఏకీకరణ; హర్ కిషన్ బాల గురువు.
9 తేగ్ బహదూర్కాశ్మీరీ పండితుల మత స్వేచ్ఛను కాపాడినందుకు ఢిల్లీలో ఔరంగజేబ్ ఉరితీశాడు (1675).
10 గోబింద్ సింగ్ఆనంద్‌పూర్లో ఖల్సా (1699) స్థాపించాడు, ఐదు 'క'లు (కేశ్, కంఘా, కడా, కృపాణ్, కచ్చేరా); గురు గ్రంథ్ సాహిబ్‌ను శాశ్వత గురువుగా ప్రకటించాడు.

రంగంప్రభావం
రాజకీయంఉద్రిక్తతను తగ్గించాయి; అక్బర్ సుల్హ్-ఇ-కుల్కు తోడ్పడ్డాయి; కానీ సిక్కు–మొఘల్ ఘర్షణ రాజకీయ శక్తిగా (ఖల్సా) ఎదిగింది.
సమాజంకులాన్ని ప్రశ్నించాయి; చేతివృత్తి, కింది కులాల భక్తులు (కబీర్ నేతగాడు, రవిదాస్ చర్మకారుడు, నామదేవ్ దర్జీ, సేన మంగలి); స్త్రీ భక్తుల స్థానం.
ఆర్థికంభక్తులు తరచూ వర్తకం, చేతివృత్తులతో జీవించారు (శ్రమ గౌరవం); లంగర్ పేదలకు అన్నం పెట్టింది; దర్గాలకు దానాలు అందాయి, యాత్రికులు, వాణిజ్యం వచ్చాయి.
మతం, భాష, సంస్కృతిసిక్కు మతం పుట్టుక; హిందీ, బెంగాలీ, మరాఠీ, తెలుగు, కన్నడ, అస్సామీ, పంజాబీ భాషల వృద్ధి; కొత్త సంగీతం, భక్తి సాహిత్యం.

  2. B. శంకరదేవుడు
  3. C. వల్లభాచార్య
  4. D. ఏకనాథ్

జవాబు: B. అస్సాంకు చెందిన శంకరదేవుడు (1449–1568).

గుర్తుచేసుకోండి: నోట్స్ మూసి మీ మాటల్లో రాయండి

1. భక్తులను ప్రాంతాల వారీగా ఒక్కో అంశంతో రాయండి. 2. నాలుగు సూఫీ సిల్సిలాలు, వారి భక్తులు, తేడాలు రాయండి. 3. పది గురువులు, భక్తి–సూఫీ పోలిక రాయండి.

పాలిటీ · పార్లమెంటు: నిర్మాణం, అధికారాలు, బిల్లులు, బడ్జెట్

ముందు అర్థం చేసుకోండి

ఇది ఏమిటి? పార్లమెంటు కేంద్రం యొక్క చట్టాలు చేసే, ధనాన్ని నియంత్రించే సంస్థ. ఈ రోజు 9వ రోజు కంటే లోతుగా: ఎవరు సభ్యులు కాగలరు, ఎలా పనిచేస్తుంది (సమావేశాలు, తీర్మానాలు, కమిటీలు), బిల్లు చట్టంగా ఎలా మారుతుంది, బడ్జెట్ ఎలా ఆమోదిస్తారు. ముఖ్యమైన ఆలోచన: పార్లమెంటు అనుమతిస్తేనే ప్రభుత్వం ఖర్చు చేయగలదు, పన్ను వేయగలదు (అ. 265: *చట్ట అధికారం లేకుండా పన్ను లేదు*; అ. 266: చట్టం లేకుండా సంఘటిత నిధి నుండి డబ్బు లేదు).

1. నిర్మాణం, సభ్యత్వం, స్పీకర్

అంశంవివరాలు
సభ్యులులోక్‌సభ: గరిష్ఠం 550 (రాష్ట్రాల నుండి 530, UTల నుండి 20); 104వ సవరణ (2019) ఆంగ్లో-ఇండియన్ నామినేషన్ రద్దు చేసింది (ముందు 552); 543 ఎన్నికైనవారు. రాజ్యసభ: గరిష్ఠం 250 (238 + 12 నామినేటెడ్). సీట్లు 2026 తర్వాత మొదటి జనాభా లెక్కల వరకు 1971 జనాభా లెక్కల ప్రకారం స్థిరం (42, 84వ సవరణలు); SC, ST లకు స్థానాలు రిజర్వ్ (అ. 330).
అర్హతలు (అ. 84)భారత పౌరుడు; 25 ఏళ్లు (లోక్‌సభ), 30 ఏళ్లు (రాజ్యసభ); ఇతర అర్హతలు ప్రజా ప్రాతినిధ్య చట్టం, 1951 ప్రకారం; ప్రమాణం చేయాలి.
అనర్హత (అ. 102)ప్రభుత్వం కింద లాభదాయక పదవి; కోర్టు ప్రకటించిన అస్వస్థ మనస్కత; దివాలా తీసినవాడు; పౌరుడు కాకపోవడం లేదా విదేశీ పౌరసత్వం; చట్టం ద్వారా అనర్హత; పదవ షెడ్యూల్ కింద ఫిరాయింపు.
ఫిరాయింపు నిరోధం (పదవ షెడ్యూల్)52వ సవరణ (1985) ద్వారా చేర్చారు; సభ్యుడు పార్టీ సభ్యత్వాన్ని స్వచ్ఛందంగా వదిలినా లేదా పార్టీ విప్‌కు వ్యతిరేకంగా ఓటు వేసినా అనర్హుడు; అధ్యక్షుడు నిర్ణయిస్తాడు; కిహోటో హోలోహన్ (1992) ఈ నిర్ణయం కోర్టు సమీక్షకు లోబడుతుందని తీర్చింది; 91వ సవరణ (2003) 'మూడో వంతు చీలిక' మినహాయింపు తీసివేసి మూడింట రెండు వంతుల విలీనం మాత్రమే ఉంచింది.
స్పీకర్ (అ. 93–96)లోక్‌సభ తన సభ్యుల నుండి ఎన్నుకుంటుంది; అధ్యక్షత, క్రమశిక్షణ, బిల్లు ద్రవ్య బిల్లా కాదా నిర్ణయం (తుది, అ. 110(3)), టై అయితే మాత్రమే నిర్ణాయక ఓటు; డిప్యూటీ స్పీకర్‌కు రాజీనామా; ప్రస్తుత సభ్యులందరి (ప్రభావ మెజారిటీ) తీర్మానం, 14 రోజుల నోటీసుతో తొలగింపు; ప్రారంభంలో ప్రొటెం స్పీకర్ ప్రమాణం చేయిస్తాడు.

2. పార్లమెంటు ఎలా పనిచేస్తుంది

లక్షణంవివరాలు
సమావేశాలు (అ. 85)రాష్ట్రపతి సమావేశపరుస్తారు; రెండు సమావేశాల మధ్య 6 నెలల కంటే ఎక్కువ విరామం కూడదు; మూడు సమావేశాలు: బడ్జెట్ (ఫిబ్రవరి–మే), వర్షాకాలం (జూలై–ఆగస్టు), శీతాకాలం (నవంబర్–డిసెంబర్); కోరం = సభ్యుల్లో 1/10 (అ. 100).
ప్రశ్నోత్తరాల గంట, జీరో అవర్ప్రశ్నోత్తరాల గంట (మొదటి గంట; నక్షత్ర, నక్షత్రం లేని, స్వల్ప నోటీసు ప్రశ్నలు) కార్యనిర్వాహక వ్యవస్థపై నియంత్రణ; జీరో అవర్ (ప్రశ్నోత్తరాల తర్వాత) అత్యవసర అంశాలకు భారతీయ ఆవిష్కరణ (నియమాల్లో లేదు).
తీర్మానాలువాయిదా తీర్మానం (అత్యవసర ప్రజా అంశం; లోక్‌సభ మాత్రమే; 50 మంది మద్దతు); దృష్టి ఆకర్షణ; అవిశ్వాసం (లోక్‌సభ మాత్రమే; 50 మంది మద్దతు); నిందా తీర్మానం; హక్కుల తీర్మానం; గ్రాంట్ల డిమాండ్లపై కోత తీర్మానాలు (విధాన కోత రూ. 1, పొదుపు కోత, సంకేత కోత రూ. 100).
కమిటీలుప్రజా పద్దుల కమిటీ (22: 15 LS + 7 RS; సంప్రదాయంగా ప్రతిపక్ష సభ్యుడు అధ్యక్షుడు; CAG నివేదికలను పరిశీలిస్తుంది); అంచనాల కమిటీ (30, LS మాత్రమే); ప్రభుత్వ రంగ సంస్థల కమిటీ (22); శాఖా సంబంధిత స్థాయీ సంఘాలు (24, 1993 నుండి; ఒక్కోదానిలో 31 సభ్యులు); సెలెక్ట్, జాయింట్ కమిటీలు.
హక్కులుపార్లమెంటులో వాక్ స్వాతంత్ర్యం (అ. 105), చెప్పిన, వేసిన ఓటుకు కోర్టు చర్యల నుండి రక్షణ; సమావేశ సమయంలో సివిల్ కేసుల్లో అరెస్టు రక్షణ; ధిక్కార అధికారాలు.

3. బిల్లులు: రకాలు, ఆమోదం

సాధారణ బిల్లు చట్టంగా మారే విధానం
రకంనియమాలు
సాధారణ బిల్లు (అ. 107–108)ఏ సభలోనైనా ప్రవేశపెట్టవచ్చు; సాధారణ మెజారిటీ కావాలి; రాజ్యసభ సవరించవచ్చు లేదా తిరస్కరించవచ్చు; ప్రతిష్టంభన: ఉమ్మడి సమావేశం (అ. 108); రాష్ట్రపతి ఆమోదించవచ్చు, నిలిపివేయవచ్చు లేదా ఒకసారి తిప్పి పంపవచ్చు.
ద్రవ్య బిల్లు (అ. 110)పన్నులు, రుణాలు, సంఘటిత లేదా ఆకస్మిక నిధి, విభజన వంటి అంశాలతో మాత్రమే వ్యవహరిస్తుంది; లోక్‌సభలోనే, రాష్ట్రపతి సిఫార్సుపై ప్రవేశపెట్టాలి; స్పీకర్ ధ్రువీకరిస్తారు (తుది); రాజ్యసభ 14 రోజుల్లో మార్పులు సిఫార్సు మాత్రమే చేయగలదు; లోక్‌సభ వాటిని అంగీకరించవచ్చు లేదా తిరస్కరించవచ్చు; RS 14 రోజుల్లో తిప్పి పంపకపోతే ఆమోదించినట్లే; ఉమ్మడి సమావేశం లేదు; రాష్ట్రపతి దీన్ని తిప్పి పంపలేరు (ఆమోదం లేదా నిలిపివేత మాత్రమే).
ఆర్థిక బిల్లు (అ. 117)వర్గం I: ద్రవ్య అంశాలతో పాటు ఇతర అంశాలు; LSలోనే, రాష్ట్రపతి సిఫార్సుతో; ఉమ్మడి సమావేశం సాధ్యం. వర్గం II: సంఘటిత నిధి నుండి వ్యయం మాత్రమే; ఏ సభైనా; రాష్ట్రపతి సిఫార్సు లేకుండా ఆమోదించలేరు.
రాజ్యాంగ సవరణ బిల్లు (అ. 368)ఏ సభైనా; ప్రత్యేక మెజారిటీ: ప్రతి సభలో మొత్తం సభ్యుల్లో మెజారిటీ, హాజరై ఓటు వేసినవారిలో 2/3; సమాఖ్య అంశాలకు కనీసం సగం రాష్ట్రాల ఆమోదం; ఉమ్మడి సమావేశం లేదు; రాష్ట్రపతి ఆమోదించాలి (24వ సవరణ). కేశవానంద భారతి (1973): పార్లమెంటు మౌలిక నిర్మాణాన్ని మార్చలేదు.

సాధారణ బిల్లు దశలు: (1) మొదటి పఠనం: ప్రవేశం. (2) రెండవ పఠనం: సాధారణ చర్చ, తర్వాత కమిటీ దశ (క్లాజుల వారీ), తర్వాత నివేదిక దశ. (3) మూడవ పఠనం: తుది ఓటు. తర్వాత రెండవ సభ అవే దశలు పునరావృతం చేస్తుంది, రాష్ట్రపతి ఆమోదిస్తారు. లోక్‌సభ రద్దయినప్పుడు లోక్‌సభలో పెండింగ్‌లో ఉన్న బిల్లు రద్దవుతుంది; రాజ్యసభలో పెండింగ్‌లో ఉండి లోక్‌సభ ఆమోదించని బిల్లు రద్దుకాదు.

4. బడ్జెట్

కేంద్ర బడ్జెట్
పదంఅర్థం
వార్షిక ఆర్థిక ప్రకటన (అ. 112)బడ్జెట్: సంవత్సరానికి (ఏప్రిల్ 1 నుండి మార్చి 31) అంచనా ఆదాయం, వ్యయం; సంఘటిత నిధిపై భారం మోపిన వ్యయాన్ని ఇతర వ్యయం నుండి వేరుగా చూపుతుంది. లోక్‌సభలో ఫిబ్రవరి 1న ప్రవేశపెడతారు (2017 నుండి; రైల్వే బడ్జెట్‌ను 2017లో విలీనం చేశారు).
సంఘటిత నిధి (అ. 266(1))ప్రభుత్వ అన్ని ఆదాయాలు, రుణాలు, తిరిగి చెల్లింపులు; విభజన చట్టం ద్వారా మాత్రమే డబ్బు తీసుకోవచ్చు.
ఆకస్మిక నిధి (అ. 267)ఊహించని వ్యయం కోసం రాష్ట్రపతి అధీనంలో ఉండే (చట్టం నిర్ణయించిన మొత్తం) 'ఫ్లోట్', తర్వాత పార్లమెంటు భర్తీ చేస్తుంది; ప్రజా ఖాతా (అ. 266(2)) భవిష్య నిధులు, చిన్న పొదుపులు, డిపాజిట్లను కలిగి ఉంటుంది.

ముందు అర్థం చేసుకోండి

ఇది ఏమిటి? నిష్పత్తి ఒకే రకమైన రెండు రాశులను భాగహారంతో పోలుస్తుంది: తరగతిలో 20 బాలురు, 30 బాలికలు ఉంటే బాలురు : బాలికలు = 20 : 30 = 2 : 3. దీనికి ప్రమాణం లేదు, ఒకటి మరొకదానికి ఎన్ని రెట్లు (లేదా ఏ భాగం) అని చెబుతుంది. అనుపాతం అంటే రెండు నిష్పత్తులు సమానం: 2 : 3 = 4 : 6. భాగస్వామ్యం, మిశ్రమాలు, వయసులు, వేగం–సమయం–పని, శాతాలు దాదాపు అన్నీ మారువేషంలోని నిష్పత్తి లెక్కలే, కాబట్టి ఈ అంశం తర్వాతి కొన్ని రోజులకు పునాది.

నిష్పత్తి, అనుపాతం: పనిముట్లు

1. నిష్పత్తి

  • a : bలో a పూర్వపదం, b ఉత్తరపదం. రెండు రాశులు ఒకే ప్రమాణంలో ఉండాలి (ముందు రూపాయలు, పైసలు లేదా మీటర్లు, సెం.మీ.లను మార్చండి). రెండు పదాలను ఒకే సంఖ్యతో గుణిస్తే లేదా భాగిస్తే సమాన నిష్పత్తి వస్తుంది; సరళ రూపానికి తగ్గించండి.
  • పోలిక: ad > bc అయితే a : b > c : d. రకాలు: ద్విఘాత a² : b²; త్రిఘాత a³ : b³; ఉప-ద్విఘాత √a : √b; విలోమ b : a; సంయుక్త ac : bd (పూర్వపదాలను, ఉత్తరపదాలను గుణించండి).
  • రాశి N ను a : b నిష్పత్తిలో పంచితే aN/(a + b), bN/(a + b). నిష్పత్తులను కలపడం: A : B = 2 : 3, B : C = 4 : 5 అయితే B ని సమానం చేయండి (3, 4 ల క.సా.గు. 12): A : B = 8 : 12, B : C = 12 : 15, కాబట్టి A : B : C = 8 : 12 : 15.
  • రెండు పదాలకు ఒకే సంఖ్యను కలిపితే నిష్పత్తి 1 : 1కు దగ్గరవుతుంది: 3 : 5 కు 1 కలిపితే 4 : 6 = 2 : 3 (0.667), 3 : 5 (0.6) కంటే 1కు దగ్గర.

2. అనుపాతం

  • a : b = c : d (a, b, c, d అనుపాతంలో): a, d అంత్యాలు, b, c మధ్యాలు; అంత్యాల లబ్ధం = మధ్యాల లబ్ధం: ad = bc. ప్రతి త్రైరాశిక లెక్కలో వాడే అడ్డు గుణకార నియమం ఇదే.
  • అవిచ్ఛిన్న అనుపాతం a : b = b : c: b² = ac, కాబట్టి b = √(ac) మధ్యానుపాతం. a, b ల తృతీయానుపాతం: a : b = b : x ⇒ x = b²/a. a, b, c ల చతుర్థానుపాతం: a : b = c : x ⇒ x = bc/a.
లక్షణం (a : b = c : d అయితే)ఫలితం
ఇన్వర్టెండోb : a = d : c
ఆల్టర్నెండోa : c = b : d
కాంపొనెండో(a + b) : b = (c + d) : d
డివిడెండో(a − b) : b = (c − d) : d
కాంపొనెండో, డివిడెండో(a + b) : (a − b) = (c + d) : (c − d)
ఉదాహరణ

ఉదాహరణ: (x + y) : (x − y) = 7 : 3 అయితే, కాంపొనెండో, డివిడెండో వాడితే: 2x : 2y = (7 + 3) : (7 − 3) = 10 : 4, కాబట్టి x : y = 5 : 2. వ్యత్యాసం: ప్రత్యక్ష (y/x స్థిరం: ఎక్కువ సరుకు, ఎక్కువ ఖర్చు), విలోమ (xy స్థిరం: ఎక్కువ మంది, తక్కువ రోజులు). భాగస్వామ్యం: లాభం (మూలధనం × కాలం) నిష్పత్తిలో పంచుతారు. A ₹30,000 ను 8 నెలలు, B ₹40,000 ను 6 నెలలు పెడితే నిష్పత్తి 240 : 240 = 1 : 1.

పరీక్షలో ఉచ్చు

ad = bc; మధ్యానుపాతం = √(ac); తృతీయానుపాతం = b²/a; చతుర్థానుపాతం = bc/a; వాటా = (భాగం / మొత్తం భాగాలు) × N; నిష్పత్తులు కలపడం: ఉమ్మడి పదాన్ని సమానం చేయండి; కాంపొనెండో-డివిడెండో: (a+b)/(a−b) = (c+d)/(c−d); భాగస్వామ్యం = మూలధనం × కాలం.
